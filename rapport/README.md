# Sources LaTeX du rapport

- Compiler : `./build.sh` (utilise Tectonic s'il est installé, sinon `latexmk -xelatex` ; sans moteur, le script explique comment en installer un). Le résultat est `rapport/rapport.pdf` ; le script affiche les avertissements du journal et conserve `rapport.log` et `rapport.bbl` (bibliographie compilée, à joindre aux sources pour arXiv ou une revue).
- Moteur : XeLaTeX (fontspec + unicode-math ; polices TeX Gyre Pagella, TeX Gyre Heros et Latin Modern Mono, toutes fournies par TeX Live ou par le bundle Tectonic) ; babel `[english,french]` (le français est la langue principale, la bibliographie est composée en anglais) ; bibliographie BibTeX dans `references.bib` (style plainnat).
- Figures : `figures/*.pdf` (et un aperçu `.png`), produites par `figures.py` à partir des mêmes fichiers que `demo.py` (prédictions de validation de `weights_holdout/`, vérité du kit, calibration ajustée sur l'autre année, référence gradient boosting), sans titre interne, avec des libellés accentués et la virgule décimale. Les régénérer depuis la racine du dépôt : `.venv/bin/python rapport/figures.py` (une dizaine de secondes).
- Archive de soumission : `rapport.tex`, `references.bib`, `rapport.bbl` et le dossier `figures/` suffisent (aucun fichier n'est lu hors de ce dossier) ; par exemple `tar czf rapport-sources.tgz rapport.tex references.bib rapport.bbl figures/*.pdf`.
